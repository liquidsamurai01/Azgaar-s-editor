# Alternate History Second Brain

An Obsidian-compatible vault (plain Markdown, works in any editor). Open the `second-brain` folder as a vault.

## Workflow
1. **Capture** anything in `00-Inbox/` (use `Templates/Inbox-Note`). Triage weekly.
2. **Research** goes in `06-Research/` (one note per source or topic, using the Source and Research templates).
3. **Decide** what changes in the world: log it in `01-Divergence/Ripple-Effects` and `02-Timeline/Altered-Timeline`.
4. **Write** with `05-Series/` open: Series Bible, per-book notes, plot threads.
5. **Check** `07-Continuity/` before and after drafting: canon rules, contradictions, open questions.

## Conventions
- Every note has frontmatter (`type`, `status`, `era`, `book`). Templates set this up.
- `status`: `idea` -> `draft` -> `canon` -> `revised`. Only `canon` notes are binding on the books.
- Link generously with `[[wikilinks]]`. A fact lives in one note; everywhere else links to it.
- Date format: `YYYY-MM-DD` (use `YYYY` or `YYYY-MM` when unsure). Mark altered-history dates `(AH)`.
- Map: the repo's Azgaar Fantasy Map Generator can draw the altered world; export `.map` files into `03-World/Places/maps/`.
